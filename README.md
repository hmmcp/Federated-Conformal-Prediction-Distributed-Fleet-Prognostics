#Federated Conformal Approach for Trustworthy Uncertainty Quantification in Distributed Fleet Prognostics

##This repository provides the code for the numerical study of the proposed Federated Conformal Approach for Trustworthy Uncertainty Quantification in Distributed Fleet Prognostics framework.

For methodological details, please refer to our manuscript:
https://www.techrxiv.org/doi/full/10.36227/techrxiv.176902673.30333692/v1

The results generated by this main.py (with functions.py and models.py) correspond to section 5.3.1 in the manuscript, using c-mapss dataset, and ADNI.py correspond to section 5.3.2 in the manuscript, using ADNI dataset.

RUL Prediction
For the Remaining Useful Life (RUL) prediction task, we use a Long Short-Term Memory (LSTM) network as the backbone neural network architecture. Quantile Regression (QR) is used as the baseline uncertainty quantification method to generate prediction intervals.

We evaluate three uncertainty quantification approaches:

1. No CP – Prediction intervals generated directly by the baseline QR model without conformal calibration.
2. FCP – Prediction intervals calibrated using the baseline Federated Conformal Prediction (FCP) approach.
3. Proposed Method – Prediction intervals calibrated using the proposed Multilevel HMM-based Federated Conformal Prediction approach.

The numerical experiments compare these methods in terms of their empirical coverage and prediction interval width under heterogeneous federated environments.

Simulation.py provide the code generates the experiments using simulated data.

We design four experimental settings to examine whether the proposed approach remains effective under various forms of model misspecification and heterogeneity: (i) different numbers of HMM latent states, (ii) violations of the left-to-right transition structure, (iii) violations of the shared emission assumption, and (iv) fleet-level heterogeneity. 

We simulate a total of 5 fleets, each fleet contains 20 units. For each fleet, data are split into training and calibration subsets (70% / 30%) at the unit level. A separate test fleet of 20 units is generated with a different transition matrix to induce a distribution shift.

An LSTM-based quantile regression (QR) model using the pinball loss is trained as baseline model for Conformal prediction. We compare three approaches: (1) QR without CP, (2) FCP based on partial exchangeability, and (3) the proposed HMM-based CP method. To provide a more comprehensive evaluation, both federated and centralized training settings are considered. For all results reported, we iterate the model for 10 times and report the average coverage and width.

By default, hyper parameter "N_REPS" (for number of iterations) is set to 10. For a quick reproducibility check or to verify that the code runs correctly on your system, you may reduce N_REPS to a smaller value (e.g., 1 or 2).
